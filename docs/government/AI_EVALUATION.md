# AI and routing evaluation status

No production LLM answer path is enabled in the source-routing allowlist. There is no approved golden corpus with expected authority, source set, urgency recall, citation precision, or abstention accuracy. The existing backend suite contains synthetic unit fixtures, not evidence of legal or jurisdiction accuracy.

Before enabling any model-assisted extraction, create a versioned, privacy-reviewed corpus across civic domains and Indian languages; label expected facts, jurisdiction, urgent flag, allowed/forbidden authorities, source evidence and abstention; evaluate extraction separately from deterministic routing; measure false negatives for urgent signals and citation mismatch; retain reviewer adjudication; and block release on an approved threshold. Do not train on citizen inputs by default.

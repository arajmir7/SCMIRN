# Data residency status

The repository does not establish an approved production cloud, state data center, region, backup region, or external processor location. No residency claim can be made for production records. Browser map/geocoding providers and any future AI, notification, identity, or storage providers require a deployment-specific data-flow and contract review.

Before a pilot, the data owner must approve primary and backup locations, support access, subprocessors, cross-border transfers, encryption/key ownership, log retention and deletion propagation. See [`../compliance/DPDP_READINESS_MATRIX.md`](../compliance/DPDP_READINESS_MATRIX.md).
